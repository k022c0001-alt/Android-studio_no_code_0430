Google API 設定

Google Maps API キーを登録・管理します

⚠️ APIキーはブラウザのローカルストレージに難読化して保存されます。
本番アプリでは必ず Google Cloud Console でキーに適切な制限をかけてください。
Maps API キー
キー取得手順
  1. 1 Google Cloud Console でプロジェクトを作成または選択
  2. 2 「APIとサービス」→「ライブラリ」から Maps SDK for Android を有効化
  3. 3 「認証情報」→「認証情報を作成」→「APIキー」をクリック
  4. 4 作成されたキーを上のフィールドに貼り付けて「保存」
  5. 5 「キーを制限」でAndroidアプリのパッケージ名・SHA-1を設定（推奨）
